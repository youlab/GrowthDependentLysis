# Ecological Modeling and Simulation

This directory contains Jupyter notebooks associated with the ecological modeling and simulation analyses in the study *Growth-dependent killing can preserve microbial diversity during antibiotic treatment*.

The simulations use a generalized Lotka–Volterra (gLV) framework to investigate how growth-dependent antibiotic-induced lysis influences microbial population dynamics and community diversity.

## Contents

| Notebook | Description | Related results |
|---|---|---|
| `gLV_simulation_Shannon.ipynb` | Simulates the effects of growth–lysis coupling and ecological interactions on Shannon diversity. | Supplementary Fig. S15; Supplementary Note 1 |
| `gLV_simulation_debris.ipynb` | Evaluates how biomass residue accumulation during cell lysis affects the inference of lysis rates. | Supplementary Fig. S9; Supplementary Note 3 |
| `gLV_simulation_net_rate_fitting.ipynb` | Evaluates the accuracy of polynomial fitting for estimating population net rates from discretely sampled biomass trajectories. | Supplementary Fig. S7; Supplementary Note 2 |

## Modeling framework

The simulations are based on a generalized Lotka–Volterra model describing the growth and loss of individual microbial populations.

Growth-dependent lysis is represented by a linear relationship between effective growth rate and lysis rate.

The simulations examine three aspects of the modeling framework:

1. The consequences of growth–lysis coupling for microbial diversity.
2. The effects of biomass residue accumulation on inferred lysis rates.
3. The accuracy of net-rate estimation from discrete biomass measurements.

Model equations, assumptions, and parameter definitions are provided in Supplementary Notes 1–3.

```bash

```

Run the notebook cells sequentially using **Run All Cells**.

```bash

  --output executed_net_rate_fitting.ipynb
```

## Expected results

### Net-rate fitting simulation

The notebook evaluates the accuracy of net-rate estimates obtained by fitting third-order polynomials to log-transformed biomass trajectories.

As described in Supplementary Note 2, simulations examine different interaction strengths and lysis-rate heterogeneity levels. Each simulation condition uses 100 independent random seeds.

The estimated net rates are compared with the known values generated by the simulation model.

### Biomass residue simulation

The notebook evaluates how residual biomass remaining after lysis can bias OD-derived estimates of lysis rates.

Results are compared between simulations with and without biomass residue accumulation.

### Shannon diversity simulation

The notebook examines how different growth–lysis coupling relationships influence the maintenance of microbial diversity in communities with ecological interactions.

The analysis compares simulated community diversity across different model conditions.

## Reproducibility

The simulations include stochastic components, including random interaction matrices and variation in lysis rates.

To reproduce the results, users should use the same model parameters, random seeds, software versions, and numerical procedures as the original analyses.

Where random seeds are generated dynamically, repeated executions may produce slightly different numerical results.

For detailed model definitions and simulation settings, refer to Supplementary Notes 1–3.
